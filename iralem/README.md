## Introdução
Este projeto tem como objetivo principal apresentar a estruturação, o desenvolvimento e os conceitos fundamentais iniciais na criação de uma Rede Neural. Durante esta fase, exploramos a arquitetura básica do modelo, o processamento dos dados de entrada, e a lógica de treinamento utilizada para permitir que a rede comece a aprender padrões. Esta base serve como alicerce para implementações mais complexas e profundas no campo de Inteligência Artificial e Deep Learning.
